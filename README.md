# ☕ 커피 주문 시스템

## 📌 프로젝트 개요

본 시스템은 다수의 서버 환경에서도 안정적으로 동작하는 커피 주문 시스템을 목표로 한다.  
특히 **동시성 제어**, **데이터 일관성**, **확장성**을 고려하여 설계하였다.

---

## 1. 요구사항 분석 및 비즈니스 정책

### 🔍 주요 문제 정의

1. **포인트 차감 시 동시성 문제**
   - 동일 사용자의 다중 요청으로 포인트가 중복 차감될 수 있음
   - 최악의 경우 포인트가 음수가 되는 문제 발생

2. **인기 메뉴 집계 성능 문제**
   - DB 기반 실시간 집계 시 성능 저하 발생

3. **주문 이벤트 비동기 처리 필요**
   - 주문 데이터를 외부 시스템(로그/분석)으로 전달 필요

---

### 🛠 해결 전략

- Redis 분산락을 통한 동시성 제어
- Redis ZSet을 활용한 인기 메뉴 집계
- Kafka를 통한 주문 이벤트 비동기 처리

---

### 📌 비즈니스 정책

- 메뉴 재고는 무한으로 가정
- 결제는 포인트 기반으로만 수행
- 포인트는 음수가 될 수 없음
- 포인트 차감은 동시성 제어 대상

---

## 2. 기능 목록

### 🔐 인증
- 회원가입
- 로그인 (JWT 기반 간단 인증)

### ☕ 메뉴
- 커피 메뉴 목록 조회 (더미 데이터)

### 💰 포인트
- 포인트 충전
- 포인트 환불
- 포인트 차감 (주문 시)

### 🛒 주문
- 커피 주문 및 결제
- 주문 생성 및 상태 관리
- 주문 이벤트 Kafka 전송

### 📊 인기 메뉴
- 인기 메뉴 집계 (Redis ZSet 기반)
- 인기 메뉴 조회

---

## 3. 아키텍처 설계

### 🏗 전체 구조

```text
[Client]
   ↓
[Spring Boot App (멀티 인스턴스)]
   ↓
 ┌───────────────┐
 │ Redis         │
 │ - 분산락        │
 │ - ZSet        │
 └───────────────┘
   ↓
[MySQL]
   ↓
[Kafka]
   ↓
[Consumer (로그/분석)]

---

### 🔥 주문 처리 흐름

1. Client → 주문 요청
2. Redis 분산락 획득 (userId 기준)
3. 포인트 조회 및 차감 (DB)
4. 주문 생성 (DB)
5. Redis ZSet 증가 (인기 메뉴 집계)
6. Kafka 이벤트 전송
7. 락 해제

---

### ⚙️ 기술 선택

#### ✅ Redis
- 분산락 → 동시성 제어
- ZSet → 인기 메뉴 실시간 집계

#### ✅ Kafka
- 주문 처리와 데이터 수집을 분리하기 위해 사용
- 비동기 처리로 성능 저하 방지 및 확장성 확보

#### ✅ k6
- 동시 요청 테스트
- Race Condition 검증

---

## 4. 동시성 및 핵심 로직 설계

### ⚠️ 동시성 문제 정의

동일 사용자가 동시에 여러 주문 요청을 보낼 경우,  
포인트 차감 과정에서 race condition이 발생할 수 있다.

이로 인해 포인트가 중복 차감되거나 음수가 되는 문제가 발생할 수 있다.

---

### 🛠 해결 전략

사용자 ID 기준으로 Redis 분산락을 적용하여  
동시에 하나의 요청만 처리되도록 설계하였다.

---

### 🔄 트랜잭션 처리

포인트 차감과 주문 생성은 하나의 트랜잭션으로 처리하여  
데이터 일관성을 보장한다.

즉, 하나라도 실패할 경우 전체 작업은 롤백된다.

---

### 🔁 주문 처리 로직

1. Redis 분산락 획득 (userId 기준)
2. 사용자 포인트 조회
3. 포인트 충분 여부 검증
4. 포인트 차감
5. 주문 생성
6. Redis ZSet score 증가 (주문 완료 기준)
7. Kafka 이벤트 전송
8. 락 해제

---

### ⚠️ 예외 처리 전략

- 락 획득 실패 시 일정 횟수 재시도 후 실패 처리
- Kafka 전송 실패 시 로그 기록 및 재처리 전략 적용

---

## 5. 부하 테스트

k6를 활용하여 동시 요청 환경에서 시스템의 안정성을 검증하였다.

- 동일 사용자 다중 요청 시 포인트 정합성 유지 확인
- 중복 결제 및 음수 포인트 발생 방지 검증
